# JobReceipts

Employees photograph material receipts on their phone. AI reads the employee, job and materials; the office reviews cost, markup (28% by default) and profit, then approves a **change order** (from your Google Doc template) or an **invoice**. Both are saved in the job's folder, named exactly like it, with the vendor on every line, and sent to **QuickBooks Online**.

- **Setup:** [SETUP.md](SETUP.md)
- **Install files:** [`dist/apps-script/`](dist/apps-script/), generated by `node build.mjs`
- **Build preview:** `preview.html` (read-only screens with made-up sample data)

## Layout

```
core/         shared logic, runs on the server (Apps Script) and in the browser
  pricing.js    cost (tax included), markup, billed, profit
  match.js      job folder matching by name and/or address
  documents.js  change order / invoice content, naming and numbering
  quickbooks.js QuickBooks Online request bodies
  extract.js    AI receipt-reading request and answer checks
apps-script/  Google Apps Script server: roles, storage, Drive, Docs, QuickBooks OAuth
ui/           the app page (employee + admin)
demo/         sample data and a stand-in back end for the preview and browser tests
test/         unit tests + end-to-end tests of the server against fake Google services
```

## Develop

```bash
npm test               # core logic, AI request/answer handling, full server flows
node build.mjs         # regenerate dist/apps-script after changing core/, ui/ or apps-script/
node build.mjs --check # fails if dist/apps-script is stale (CI runs this)
```

Open `demo/app.html` through any local web server to click through the app with sample data (`#employee` for the employee view).
